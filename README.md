# Your Philippine Guide

reference the image based from the prompt and here is the related prompt . Build a polished, production-quality PinoyLokal homepage UI prototype based on this product concept.

Product

PinoyLokal is a Filipino local information and discovery platform.

Positioning:

“Your Local Guide to the Philippines.”

It helps Filipinos discover food, places, local businesses, skilled providers, practical guides, money information, travel, culture, and useful tools.

The experience must be public/non-login-first.

For this first build, focus ONLY on the homepage visual experience and responsive navigation. Use mock/static data. Do NOT build backend, authentication, payments, booking, messaging, social-media integrations, or an advertising management system yet.

Visual direction

Use a polished modern Philippine aesthetic:

White/light background

Deep Philippine-inspired blue

Red accents

Warm yellow/sun accent

Rounded cards

Subtle shadows

Generous whitespace

Strong typography

High-quality Philippine photography

Responsive desktop/tablet/mobile layouts

The design should feel like a real consumer web platform, not a generic admin dashboard.

Avoid excessive gradients, excessive animations, and overly complicated UI.

Important scope constraint

This first build is a frontend product/design prototype.

Prioritize:

Visual quality

Homepage layout

Hero destination rotation

Search experience

Category navigation

Provider directory presentation

Tools presentation

Sponsored campaign presentation

Responsive design

Use mock data and placeholder interactions where backend functionality is not available.

Do not spend the build implementing backend systems or integrations.
